Other calendar apps (Gmail, Apple): add this calendar address —

https://aka.ms/mfm-frontiercircle-calendar-ics
How to add it in Google or Apple Calendar
  • Google Calendar (web): next to Other calendars, select + → From URL, paste the address, then select Add calendar.
  • Apple Calendar (Mac): choose File → New Calendar Subscription, paste the address, then select Subscribe.

Tip: Subscribing keeps your calendar up to date. Downloading/importing an ICS file is only a one-time snapshot.
